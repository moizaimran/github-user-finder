# GitHub User Finder 🔎

A GitHub user search application built with HTML, CSS, and JavaScript. The application uses the GitHub REST API to search for GitHub users and display their profile information dynamically.

## 🚀 Features

* Search for GitHub users by username
* Fetches real-time user data from the GitHub API
* Displays user profile information dynamically
* Shows profile picture and basic account details
* Displays GitHub statistics and profile information
* Handles invalid or unavailable usernames
* Interactive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub REST API
* Fetch API
* DOM Manipulation
* Async/Await
* Event Listeners

## 🔗 API

This project uses the **GitHub REST API** to retrieve public GitHub user information.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter a GitHub username in the search field.

5. Click the search button to view the user's profile information.
